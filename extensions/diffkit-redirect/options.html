Redirect rules

Rule format 
{
  "id": "github-pull-details",
  "label": "Pull request details",
  "enabled": true,
  "match": {
    "urlRegex": "^https://github\\.com/([^/?#]+)/([^/?#]+)/pull/(\\d+)/?$",
    "excludeUrlRegexes": []
  },
  "redirect": {
    "replacement": "https://diff-kit.com/$1/$2/pull/$3"
  }
}

label is the name shown in the popup. For a single page, use match.exactUrl with redirect.url.
